# Duck Visual Inspection Dataset

ゴム製アヒル（全長 約 36mm）を真上から撮影した外観検査用データセット。
**「不良画像を 1 枚も学習に使わない」手法の検証**を目的に設計している。

ライセンス: **CC BY 4.0**（`LICENSE` 参照）

---

## 1. 構成（67 枚）

```
data/duck/
├── train_ok/              # 学習用（正常のみ）        27 枚
│   ├── normal/  ok_normal_01.png 〜 09.png
│   ├── side/    ok_side_01.png   〜 09.png
│   └── bright/  ok_bright_01.png 〜 09.png
├── test_ok/               # 評価用・正常              30 枚
│   ├── normal/  test_ok_normal_10.png 〜 19.png
│   ├── side/
│   └── bright/
└── test_ng/               # 評価用・異常              10 枚
    ├── easy/    ng_easy_10.png   〜 12.png
    ├── medium/  ng_medium_13.png 〜 16.png
    └── hard/    ng_hard_17.png   〜 19.png
```

- 全画像 **900×900 px、PNG（無劣化）**
- ファイル名末尾の 2 桁が**個体番号**

## 2. 個体の割り振り（重要）

| 個体 | 用途 | 傷 |
|:--|:--|:--|
| #01〜#09（9 個） | **学習専用** | なし |
| #10〜#19（10 個） | **評価専用** | `test_ok` は無傷、`test_ng` は傷あり |

**学習用と評価用は個体レベルで完全に分離している。** 同じ個体が両方に入ると過学習に気づけないため。

**`test_ok` と `test_ng` は同じ 10 個体**なので、`test_ok_normal_17.png`（無傷）と
`ng_hard_17.png`（傷あり）は**同一個体の before / after** になる。傷だけが差分。

## 3. 照明 3 条件

**明るさではなく「影の向き」で条件を分けている。** 単純な輝度シフトはモデルにとって容易すぎるため。

| 条件 | 光源 | 背景の最も暗い象限 |
|:--|:--|:--|
| `normal` | 蛍光灯のみ（天井） | **左上**（明るさ 79.9） |
| `side` | デスクライトのみ（横から） | **右上**（明るさ 81.4） |
| `bright` | 蛍光灯 + デスクライト | どちらでもない（左上 90.5 / 右上 90.6） |

全体の明るさはほぼ同じ（119.9 / 122.7 / 122.7）だが、**影の位置が入れ替わる**。

## 4. 異常の難易度

| レベル | 個体 | 内容 |
|:--|:--|:--|
| `easy` | #10〜#12 | 大きな塗りつぶし・汚れ（10〜15mm） |
| `medium` | #13〜#16 | 線状の傷・塗装ムラ（5〜14mm） |
| `hard` | #17〜#19 | **幅 1mm 以下の細い線、1〜2mm の点** |

`easy` と一部の `medium` は 2024 年に作成した個体を再利用している（同一ロット・同一製品）。
`hard` は本データセットのために新規作成。

## 5. 撮影条件

| 項目 | 内容 |
|:--|:--|
| カメラ | Logicool HD Pro Webcam C920（1920×1080） |
| 固定 | アーム式スタンドで真上から |
| 背景 | 緑の布（マスキングテープで固定） |
| ROI | 元映像の (440, 81) から 900×900 を切り出し（全画像で固定） |
| 被写体サイズ | **全長 約 36mm**（個体差あり。最大 約 41mm） |
| ピント | オートフォーカス。**合焦を鮮鋭度で監視し、未合焦では撮影しない**運用 |

**被写体が ROI に占める割合**: 標準的な個体で 655〜675 px（ROI の約 73%）。
DINOv2 ViT-S/14 に 518×518 で入力した場合、**1 パッチ ≒ 実寸 1.3mm** に相当する。

## 6. 使い方の注意

**このデータセットは「正常画像だけで準備する」前提で設計されている。**

| 場面 | `test_ng` を使ってよいか |
|:--|:--|
| メモリバンクへの登録 / 学習 | **使わない** |
| 疑似欠陥の設計 | **使わない**（実際の傷を見て似せると漏洩する） |
| 閾値の決定 | **使わない** |
| **決めた構成の採点** | **使ってよい（＝試験）** |

閾値を決めるための正常スコアが必要な場合は、`train_ok` を leave-one-out で使う
（自分自身をバンクから除いてスコアリングする）。`test_ng` は一切使わない。

## 7. 既知の特性

- **個体差**: 同じ製品でも全長に最大 15%（36mm 対 41mm）の差がある。#10 と #18 が大きい
- **色**: C920 のホワイトバランスにより、実物（黄色）よりベージュ寄りに写る。全画像で一貫しているため検査には影響しない
- **背景の微小な異物**: 一部の画像の左端に布の繊維（40〜58px）が写っている。学習用・評価用の両方に均等に現れるためバイアスにはならない
